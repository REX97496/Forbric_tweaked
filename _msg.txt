kernel: KernelGameBlockEvents gets a 1.21.1 edition -- 162 -> 161, first overlay change to land

One file, ten hand-translations, eight table rows deleted, one constructor rewritten.

WHY THIS IS ONE COMMIT AND NOT FOUR. An overlay is written verbatim and no rule runs on it
(build.gradle:501-502). So the overlay must arrive already spelled in 1.21.1's own names, and the rows that
covered its sites must go in the same commit, or :539-542 fires and the branch is red in between. Splitting
it would leave a tree that does not build.

plus the constructor, which is the actual reason for the file: 1.21.1's BreakEvent has exactly one
constructor, (Level, BlockPos, BlockState, Player) -- javap -- so the five-argument form could never work
there. Event.setResult(Event$Result) exists, so:

    BlockEvent.BreakEvent forgeEvent = new BlockEvent.BreakEvent(level, neoEvent.getPos(),
            neoEvent.getState(), neoEvent.getPlayer());
    forgeEvent.setResult(seed(neoEvent.isCanceled()));
    return vetoed(forgeEvent);
